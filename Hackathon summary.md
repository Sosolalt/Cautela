# Hackathon Summary: Google Cloud Rapid Agent Hackathon

This document summarizes the key details for the **Google Cloud Rapid Agent Hackathon**. You are specifically targeting the **Arize** prize track.

---

## Core Mission

Build a functional AI agent that solves a real-world challenge (work, personal life, or hobbies). The agent must go beyond a simple chatbot by using tools to **reason, plan, and execute tasks**.

### Technical Requirements

* **Core Engine:** Google Cloud Agent Builder + Gemini 3.
* **The "Superpower":** Must integrate the **Arize MCP (Model Context Protocol) server**.
* **Functionality:** Demonstrate multi-step logic where the agent manages tools/services to complete a goal under your oversight.

---

## The Arize Prize Track

You are competing specifically within the **Arize "Bucket."**

* **1st Place:** $5,000
* **2nd Place:** $3,000
* **3rd Place:** $2,000

*Strategy Note:* Since you are competing only against other projects using Arize, your focus must be on maximizing the utility and sophistication of the **Arize MCP integration** to demonstrate measurable performance, observability, or reliability improvements in your agent.

---

## Key Dates & Logistics

* **Deadline:** June 11, 2026, at 11:00 PM GMT+2.
* **Platform:** Devpost.
* **Team Size/Location:** Public, individual or team participation allowed (must be of legal majority age).

---

## Submission Requirements

To submit a valid project, you must include:

1. **Hosted Project URL:** The live agent/interface.
2. **Public Code Repository:** Must be public and include a **clearly visible Open Source License** in the "About" section.
3. **Demo Video:** ~3 minutes in length.
4. **Track Selection:** Explicitly select the "Arize" track.
5. **Submission Form:** Complete the required Devpost fields.

---

## Judging Criteria

Your project will be evaluated on four pillars:

1. **Technological Implementation:** Quality of code and integration with Google Cloud & Arize.
2. **Design:** Quality of the user experience (UX) and overall design.
3. **Potential Impact:** Ability to solve a meaningful real-world problem.
4. **Quality of Idea:** Creativity and uniqueness of the solution.
